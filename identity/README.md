## Organizational Principles

These functions underpin identity implementations across networks, endpoints, applications, cloud, industrial systems, and IoT. Other domains should link to canonical identity concepts rather than duplicate them.

- One canonical home per subject; related subjects connect through explicit, typed links.
- These function categories are navigation groups, not necessarily mutually exclusive theoretical classes.
- Deeper implementation taxonomies and alternate indexes have not yet been established.
