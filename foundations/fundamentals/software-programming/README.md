# Software & Programming

**Division:** [Fundamentals](../README.md)  
**Architecture status:** Approved subject area  
**Content status:** Subject inventory only; canonical lessons and assessments are pending

## Scope

The concepts, languages, structures, and lifecycle mechanisms used to create executable software.

## Approved Subject Inventory

- Programming languages
- Syntax and semantics
- Programming paradigms
- Compilation and interpretation
- Runtime environments
- Modules and dependencies
- Software interfaces
- Error handling
- Testing and software lifecycle

## Content Development

Each subject will eventually receive a canonical explanation, key distinctions, mechanisms, examples, relationships, suitable educational assessments, and references. These items are **not yet completed** merely by being listed.

The content belongs in Fundamentals only insofar as it is domain-agnostic. Security-specific treatment belongs in Security Foundations; security practice belongs in Operational Foundations. Cross-domain references should link to canonical subjects rather than duplicate them.
