# Zeek

**Status: Draft**

This section will organize Zeek learning and practice around five activities:

1. **Learn:** Build foundational understanding.
2. **Architect:** Design Zeek use cases and system structures.
3. **Engineer:** Deploy, configure, integrate, and operate Zeek.
4. **Develop:** Create and maintain scripts, packages, and extensions.
5. **Analyze:** Interpret Zeek outputs and investigate network behavior.

## Working event categories

- System
- Protocol
- File
- Detection

These categories are a teaching framework, not an assertion of Zeek's official exhaustive event taxonomy.
