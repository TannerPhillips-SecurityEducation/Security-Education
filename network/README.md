# Network Knowledge

Network Knowledge is organized primarily by **network function**.

## Approved Navigation Categories

- [Architecture & Topology](architecture-topology/README.md): Network structures, designs, relationships, and segmentation
- [Infrastructure](infrastructure/README.md): Network devices, interfaces, media, and supporting systems
- [Communication & Protocols](communication-protocols/README.md): Communication mechanisms, protocol families, and exchanges
- [Addressing & Naming](addressing-naming/README.md): Addresses, identifiers, namespaces, and resolution
- [Switching & Routing](switching-routing/README.md): Forwarding, path selection, bridging, and routing
- [Network Services](network-services/README.md): Services supporting connectivity and communication
- [Network Operations](network-operations/README.md): Configuration, monitoring, troubleshooting, and maintenance

## Organizational Principles

- **Network function** is the primary navigation classification.
- Categories may overlap in subject matter. Each subject should have one canonical home and cross-category relationships should be expressed through explicit links.
- Domain-independent principles belong in Foundations, where appropriate; specialized network implementations may reference them.
- Network security practices such as NSM, NTA, and NDR are not automatically independent root navigation categories here.
- Deeper topic taxonomies remain undefined until approved.
